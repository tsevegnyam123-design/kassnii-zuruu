Ажилтны анкет

16 талбартай анкетын загвар. Бодит мэдээлэл хадгалахгүй.

Supabase-тай холбогдсон үндсэн талбаруудыг харуулна. Одоогоор зөвхөн өөрийн нэр, овгийг хадгална; бусад талбарын засвар идэвхгүй.

Нэвтэрсний дараа Supabase анкет ачаална.
