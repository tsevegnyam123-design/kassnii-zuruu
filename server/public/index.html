GS25 · Ажилтны портал
Туршилтын нэвтрэлт. Зөвхөн Supabase Authentication-д үүсгэсэн туршилтын хэрэглэгчээр нэвтэрнэ. Одоогоор ажилтны кодоор нэвтрэхгүй, анкет болон цалингийн мэдээлэл оруулахгүй.

Нэвтрэх

Supabase Auth-д бүртгэлтэй и-мэйл, нууц үгээ ашиглана.

Миний хэсэг

Админ эрх серверээр баталгаажсан. Dashboard-ийн өгөгдлийн холболт дараагийн шатанд хийгдэнэ.
